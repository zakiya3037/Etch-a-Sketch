# Etch-a-Sketch

A browser-based drawing app built with HTML, CSS, and JavaScript as part of The Odin Project Foundations course.

## Features

- Create a 16 × 16 grid by default.
- Draw by hovering the mouse over squares.
- Generate random RGB colors.
- Resize the grid from 1 to 100 squares per side.
- Keep the grid within a fixed 960 × 960 pixel area.

## Technologies Used

- HTML5
- CSS3 (Flexbox)
- JavaScript

## How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Move your mouse over the squares to draw.
4. Click **Change Grid Size** to create a different grid.
